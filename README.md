# 🌍 European Countries - EU, Schengen & Euro

An interactive map and table showing European countries and their relationship with the European Union, Schengen Area, and Eurozone.

## ✨ Features

-  Interactive map of Europe
-  EU member countries highlighted on the map
-  EU candidate and potential candidate countries highlighted
-  Former EU members highlighted separately
-  European countries outside the EU included
-  Country flags in the table
-  EU accession years
-  Schengen accession years
-  Euro adoption years
-  EU candidate-status years
-  Search countries
-  Sort the table by different columns
-  Click a country on the map to find it in the table
-  Click a country in the table to locate it on the map
-  Responsive layout for smaller screens

## 📊 Data

The project includes:

-  European Union member states
-  EU candidate countries
-  Kosovo as a potential candidate
-  European countries outside the EU
-  United Kingdom as a former EU member

An asterisk (`*`) is used for candidate-related dates where the year does not represent EU accession.


## 🛠️ Technologies

-  HTML
-  CSS
-  JavaScript
-  [Leaflet](https://leafletjs.com/) - interactive map
-  [FlagCDN](https://flagcdn.com/) - country flags
-  Europe GeoJSON data

  ## 🎯 Purpose

This project provides a visual way to compare European countries based on:

-  EU membership
-  Schengen membership
-  Euro adoption
-  EU candidate status

> It is intended primarily as an educational and informational project.
